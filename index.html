Install Guide

  1. Click the download button above to get the latest version of BatRBLX.
  2. Unzip the file to a folder on your computer.
  3. Open chrome://extensions → Enable Developer mode.
  4. Click Load unpacked and select the folder.

BatRBLX only enhances the Roblox website UI — it does not modify gameplay or access in-game systems.
